# OMIX

OMIX is a MATLAB-based computational framework for strain design in metabolic engineering. It supports mixed metabolic interventions, including reaction knockout, flux up-regulation, and flux down-regulation, within a consistent knockout-based optimization framework, while enabling efficient computation of optimal intervention strategies.

## Workflow

The OMIX pipeline consists of three main stages:

### Step 1. Preprocessing

The pipeline starts from:

```
preprocess/run_preprocessing.m
```

This script calls the preprocessing programs in the same folder to perform metabolic network preprocessing, including:

- network compression,
- candidate reaction selection.

After this step, the repository generates:

- reduced metabolic models in `data/reduced/`,
- candidate reaction sets in `data/`,
- and FVA-related intermediate files in `data/fluxFVA/`.

### Step 2. Network Expansion

After preprocessing, run:

```
network_expand.m
```

This step expands the metabolic network by introducing pseudo-reactions and pseudo-metabolites for regulatory intervention modeling. The processed model files generated in this step are used as the direct inputs of OMIX optimization, such as:

- `data/EX_succ_e.mat`
- `data/EX_etoh_e.mat`
- `data/EX_lyco_e.mat`

### Step 3. Optimization and Analysis

Once the expanded model is prepared, run:

```
omix_solver.m
```

This is the core script of OMIX, where the optimization model and all constraints described in the paper are implemented and solved.

After obtaining the predicted intervention strategies, basic validation and visualization can be performed using:

```
analyzer.m
```

For example, production envelope analysis can be carried out in this step.

------

## How to Run

The recommended execution order is:

```
preprocess/run_preprocessing.m
network_expand.m
omix_solver.m
analyzer.m
```

That is,

1. preprocess the metabolic model and generate candidate sets;
2. expand the reduced network with pseudo-reactions and pseudo-metabolites;
3. solve the OMIX optimization model;
4. analyze and validate the optimization results
